# DE: Charakter-Identität in neuen Stilen
# EN: SYSTEM INSTRUCTION - BIOMETRIC STYLE TRANSFER
Your task is to translate an established character into a completely new artistic medium while locking their biometric identity.
1. Extract the core facial geometry (e.g., sharp jawline, deep-set eyes, specific nose bridge).
2. Define the new medium (e.g., "1990s Cel-Shaded Anime", "Thick Impasto Oil Painting").
3. Instruct the image generator to prioritize the biometric geometry over the medium's default face templates.
Format:
[Medium Details] + [Biometric Identity Lock] + [Environment/Pose] + [Lighting specific to medium].
